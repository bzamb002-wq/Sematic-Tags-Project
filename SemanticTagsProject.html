Main Content

This is the main content area of the page.

Example, if you are in a page about something, like Somerset College Prep, the main tag would conatain stuff about what is the school, what it does, basically the main content.

Remember, there is only one main tag per page.

Section

This is a Section, it is where a distinct part of the page is placed.

The section tag usually contains a heading and related content.

Example: A section about the history of the school.

Remember, Section tags is way different from div, or article tags.

Article

This is an Article, it is where a self-contained composition is placed.

The article tag usually contains a heading and related content.

Example: A newspaper article covering how St. Lucie County schools could recieve better lunch programs.

Remember, Article tags is way different from div, or section tags.

Aside

This is an Aside, it is where content that is related to the main content but not essential to its understanding is placed.

The aside tag usually contains a heading and related content.

Example: A sidebar with links to related articles or resources.

Details Tag

Details tag

This is a Details tag, it is where additional information can be shown or hidden.

Example: System Requirements

Here are the system requirements for the application:

  • Processor: Intel Core i5 or AMD Ryzen 5

Footer

This is a Footer, it is where the footer of the page is placed.

The footer tag usually contains information about the author, copyright information, and related content.

Example: A footer with contact information and links to social media profiles.
